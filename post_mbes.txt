<div class="nh-post" style="font-family: 'Noto Sans TC', 'Microsoft JhengHei', sans-serif; font-size: 16px; line-height: 1.7; color: #06172E">

<p style="margin: 0 0 8px; font-size: 18px; line-height: 1.75; color: #4A5B70">當 TX、RX 換能器可以各自設定 lever arm 與安裝角（angle offset）時，這些參數不是安裝完就算了：它們會直接進入聲速改正（SVC）的計算，決定 ray tracing 從哪裡出發、往哪個方向出發。這篇從 SVC 的計算過程出發，整理 TX、RX 分開安裝時要注意的事，並以 TX、RX 封裝在同一聲納頭的一體式作為對照。不談公式推導，只談實務上最容易踩到的地方。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">兩種聲速，兩種用途</h2>
<p style="margin: 0 0 16px"><strong>表面聲速</strong>由裝在換能器附近的聲速探頭即時量測，用在聲納的<strong>波束形成</strong>：平板陣列要把波束轉到某個角度，各陣元之間的時間延遲是用這個聲速換算的。</p>
<p style="margin: 0 0 16px"><strong>聲速剖面</strong>由 CTD 或 SVP 儀下放取得，用在 <strong>ray tracing</strong>：聲波穿過不同聲速的水層時會折射，必須沿著剖面一層一層追蹤，才能把「旅行時間 + 角度」換算成正確的水深與橫向位置。</p>
<p style="margin: 0">表面聲速決定波束往哪個方向出發，剖面決定聲線怎麼彎。而波束從哪裡出發、往哪個方向出發，取決於收發換能器怎麼裝。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">一體式與分體式：差在哪裡</h2>
<p style="margin: 0 0 16px"><strong>一體式安裝</strong>：TX、RX 封裝在同一個聲納頭內，兩者的相對位置與角度出廠就固定。原廠定義聲納頭的參考點，TX、RX 相對於這個點的內部偏移已內建在系統與處理軟體中，處理時仍是把 TX、RX 分開計算，只是不需要使用者輸入。安裝時只需輸入一組 lever arm 與一組安裝角。這類系統機型不多（以 Kongsberg Discovery 為例，只有少數幾個系列），常見於中淺水、小型船或可攜式安裝。</p>
<p style="margin: 0 0 16px"><strong>分體式安裝</strong>：TX 與 RX 是兩個獨立的換能器，以 Mills cross 配置分別固定在船底，各有自己的 lever arm 與安裝角，必須分別量測、分別輸入。中深水系統的陣列動輒數公尺長，幾乎都是分體式；淺水系統也有分體式設計。</p>

<p style="margin: 0">兩者在聲速改正上的差異，主要來自三件事：安裝參數是一組還是兩組、TX 與 RX 相距多遠，以及這段距離加上發射與接收之間的時間差，能不能忽略。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">差異的根源：ray tracing 的起始向量</h2>
<p style="margin: 0 0 16px">Ray tracing 要從一個起始方向出發：這個波束在水中的入射角與方位角，也就是「波束向量」。聲速剖面再準，起始向量算錯，後面整條聲線都會跟著錯。一體式與分體式真正的分歧，就在這個起始向量怎麼算。</p>
<p style="margin: 0 0 16px">把 SVC 的計算拆開來看，每個波束都依序經過五步：先由 TX 的 Z lever arm、水線與升沉算出<strong>起始深度</strong>；再以換能器處的聲速修正 TX 傾角與 RX 波束角；接著用 TX 安裝角加上發射時刻的姿態、RX 安裝角加上接收時刻的姿態，各得到一個圓錐，兩錐的交線就是<strong>起始向量</strong>；然後沿聲速剖面做 ray tracing；最後加上 lever arm，換算到參考點。可以各自設定的安裝參數，幾乎都在 ray tracing 之前進入，這正是它們會造成資料問題、而且不容易事後修補的原因。圖 2 用同一個聲速剖面實際追蹤聲線，依序播放四種設定錯誤：RX roll 設錯讓條帶傾斜，TX pitch 設錯讓整條帶前移，TX Z 設錯讓整條帶變深，TX roll 設錯則幾乎沒有影響。</p>

<p style="margin: 0 0 16px"><strong>一體式</strong>：發射波束同樣會依縱搖做電子導向（多數機型也有首搖穩定與分扇區發射），所以波束向量一樣要同時考慮發射導向角與接收導向角。差別在於 TX、RX 在同一殼體內、相距很短，間距與相對角度由原廠內建，收發分置與時間差造成的影響小。</p>
<p style="margin: 0 0 16px"><strong>分體式</strong>：同樣依當下姿態對發射波束做電子導向，並把一個 ping 拆成多個扇區、各扇區導向角不同（依水深模式而定，以 Kongsberg Discovery MBES 為例，常見 3 到 8 個扇區）。但 TX、RX 是分開安裝、相距可達數公尺，從發射到接收之間船已移動、姿態也變了，波束實際上是「發射圓錐面」與「接收圓錐面」的交線，必須同時考慮兩個時刻、兩支陣列的角度與位置。</p>
<p style="margin: 0 0 16px">針對這個問題，加拿大 OMG 團隊發展了<strong>虛擬同心模型（VCCA）</strong>，考慮 14 個角度；後來 Hamilton（2014）再加入收發陣列之間的位置偏移與船行偏移，並對發射與接收兩條聲線分別做 ray tracing、反覆求解到兩段單程時間相加等於量測的雙程時間，成為<strong>收發分置模型（NCCA）</strong>。</p>

<p style="margin: 0 0 16px">如果把分體式的資料用簡化的「收發同體模型」處理（假設 TX、RX 同點、忽略發射導向，只用接收導向角、姿態與安裝角共 7 個角度），會差多少？一份比較這幾種模型的研究簡報給了很直接的數字：</p>
<ul style="margin: 0 0 16px; padding-left: 22px; display: flex; flex-direction: column; gap: 8px">
<li>淺水（18–28 m）：與 VCCA 相比，水深最大差約 0.34 m，約 0.2% 的點超過 1% 水深限差。影響不大，但海況變差時會增加。</li>
<li>深水（約 800–1060 m）：平面位置差最大約 44 m，約 37% 的點超過 1% 水深限差，簡化模型基本上不能用。</li>
</ul>
<p style="margin: 0 0 16px">同一份研究也指出，這些模型都把波束能量當成規則圓錐面，<strong>忽略了聲速變化對圓錐面本身的折射扭曲</strong>，在全海深環境下仍有系統誤差。換句話說，波束向量與聲速改正其實是綁在一起的問題。</p>
<p style="margin: 0">一體式也不適合套用這個簡化模型：它同樣有發射導向與分扇區發射，處理時仍應使用含發射導向角、並帶入原廠內建 TX／RX 偏移的模型。只是收發相距很短，收發分置造成的誤差遠小於分體式。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">表面聲速差一點，外側波束差多少？</h2>
<p style="margin: 0 0 16px">以平板陣列為例，假設實際表面聲速是 1503 m/s，探頭卻讀到 1500 m/s（誤差 0.2%）。波束形成時以為轉到 60°，實際指向約 60.2°。</p>
<p style="margin: 0 0 16px">在水深 50 m、斜距約 100 m 的外側波束，這 0.2° 會造成約 <strong>0.3 m 的深度誤差</strong>，而且左右對稱、越往外越大。在成果上看到的就是典型的「微笑」或「哭臉」剖面。</p>
<p style="margin: 0 0 16px">這一點兩種安裝方式都一樣，但分體式多了一層：TX 的發射導向角也是用表面聲速換算的，表面聲速錯了，沿航向的導向同樣會偏。部分機型採用弧形接收陣列，波束方向主要由陣列幾何決定，對表面聲速誤差較不敏感。</p>
<p style="margin: 0">這種誤差常被誤判成 roll 校正問題，但 roll 誤差是一邊高一邊低，聲速誤差是兩邊同時往上或往下彎，形狀不同。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">分體式：TX、RX 位置與安裝角不準的影響</h2>
<p style="margin: 0 0 16px">如圖 2，分體式系統在做 ray tracing 之前，要先用 TX、RX 各自的 lever arm 與安裝角算出兩件事：波束的起始方向（入射角與方位角），以及聲線從哪個深度開始追蹤。許多系統在處理單元內即時完成這個計算，結果直接寫進原始檔的測深資料中。</p>
<p style="margin: 0 0 16px">換句話說，安裝參數的誤差<strong>在 ray tracing 之前就進入計算</strong>（見圖 2），不是事後疊加的小改正量。角度誤差會讓整個波束扇面先轉一個角度，再沿剖面折射出去。以水深 50 m、60° 波束、表層 1545 m/s 到 35 m 降為 1528 m/s 的剖面計算：安裝角差 0.5°，落點水深差約 0.66 m、橫向差約 0.40 m；把 XYZ 轉回 0.5° 後只剩約 1 cm，淺水時近似整體旋轉。但在水深 500 m、表層約 1540 m/s、50–150 m 溫躍層降到 1500 m/s 的剖面，同樣 0.5° 的水深誤差約 6.4 m，轉回去後 60° 波束仍差約 0.5 m、65° 波束約 0.7 m。所以發現安裝角有誤時，正確的做法是修正參數後，從原始 range／angle 重新計算；淺水時把 XYZ 轉回去，只能算是近似。</p>
<p style="margin: 0 0 16px">依 Mills cross 的幾何，<strong>RX 陣列決定跨航向角度，TX 陣列決定沿航向角度</strong>，所以各項誤差影響的方向不同。反過來說，TX 的 roll 與 RX 的 pitch 是繞陣列自身長軸轉動，幾乎不改變各自的圓錐，對水深的影響很小。原廠安裝手冊的容許誤差也反映這一點：RX roll 要求 ±0.02°，TX pitch 與 heading 要求 ±0.05°，Z 要求 ±0.005 m，TX roll 與 RX pitch 則放寬到 ±0.20°。下表以水深 50 m、60° 外側波束（斜距約 100 m）估算，未計入折射放大：</p>

<p style="margin: 0 0 16px">三個實務重點：</p>
<ul style="margin: 0 0 16px; padding-left: 22px; display: flex; flex-direction: column; gap: 10px">
<li><strong>Patch test 的結果要放進對的地方。</strong>一體式只有一組安裝角，校正值直接改在這一組即可。分體式的 TX 與 RX 已依既定的安裝位置與角度固定在同一個安裝 frame 上，兩者的相對幾何不變；patch test 求得的 roll、pitch、heading 偏差，應視為整個安裝 frame 的偏差，一起套用到兩支陣列。若拆開只改其中一支，會破壞原本的相對幾何，校正值在不同扇區、不同導向角下就不會一致。</li>
<li><strong>TX、RX 的相對位置要量準。</strong>收發分置模型靠這段距離把兩個圓錐面交在正確的位置。相對位置錯了，在淺水、大導向角時最明顯，常表現為扇區交界的階差；水深增加後影響迅速變小。</li>
<li><strong>改了參數，要從原始資料重算。</strong>即時寫進檔案的 XYZ 已經用了舊參數，應在後處理時覆寫安裝參數，從原始 range／angle 重新 ray tracing。不過當時波束實際打到海底哪裡已經固定，重算只能修正點被放到哪裡，無法改變覆蓋範圍。</li>
</ul>
<p style="margin: 0">判斷順序可以這樣走：左右對稱彎曲，先查聲速；一邊高一邊低，查 roll；地物在往返測線間前後錯開，查 pitch 與時間延遲（pitch 誤差隨水深變大，latency 隨船速變大）；分體式若出現外側沿航向錯開、扇區交界錯位，再查 TX／RX 的相對 heading 與相對位置。</p>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">現場檢查清單</h2>
<ul style="margin: 0; padding-left: 22px; display: flex; flex-direction: column; gap: 10px">
<li><strong>一體式</strong>：依原廠文件確認聲納頭參考點的位置，lever arm 量到這個點；安裝角只有一組，不要自行拆成 TX、RX。</li>
<li><strong>分體式</strong>：TX、RX 分別量測 lever arm 與安裝角，特別注意兩支陣列之間的相對位置與相對方位。</li>
<li><strong>所有系統</strong>：確認表面聲速探頭的讀值有送進聲納；探頭與剖面表層差異明顯時，就是該重新下放 SVP 的訊號。</li>
<li><strong>後處理</strong>：看到左右對稱的外側彎曲，先查聲速，再查 roll。分體式資料重處理時，軟體必須讀取各扇區的發射導向角與發射時刻姿態；自行寫程式時，不要套用只看接收角的簡化模型，深水尤其如此。</li>
</ul>

<h2 style="margin: 48px 0 20px; padding-top: 40px; border-top: 1px solid #CDBF9E; font-family: 'Noto Serif TC', serif; font-size: 32px; line-height: 1.35; font-weight: 700; color: #0F3D6B">結語</h2>
<p style="margin: 0">一體式把收發幾何封裝在聲納頭裡，安裝參數少、收發間距由原廠固定，適合機動的中淺水作業。分體式換來更大的陣列，可做到更窄的波束與更深的水深，但 TX、RX 各自的位置與角度、發射導向，以及收發之間的時間差，都必須正確進入聲速改正的計算。只要換能器可以各自設定 lever arm 與安裝角，這些參數就是 SVC 計算的一部分：量得準、設得對，聲速改正才有正確的起點；發現有誤，就要從原始資料重新計算，而不是事後修補 XYZ。</p>
